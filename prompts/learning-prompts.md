# AI 辅助学习提示词

配合本系统使用。将 `【】` 中的内容替换为实际信息，附上对应模板内容效果更好。

## 定向阶段

```text
我是产品经理，想系统学习【领域】。我的使用场景是【场景】，
可用时间为【每周 X 小时，共 X 周】。
请帮我：
1. 把该领域拆成 4 层：基础层、核心层、应用层、前沿层。
2. 为每层列出最重要的 5 个知识节点，标注重要性和学习成本。
3. 按我的场景裁剪范围，明确建议暂缓的内容。
4. 为每个核心节点建议目标层级（L1 了解 / L2 理解 / L3 应用 / L4 讲授）。
输出为表格。
```

## 定制化新增知识/课程（向智能体提需求）

```text
请为我的学习系统补充新内容：
领域：【AI 技术知识 / 机器人技术知识】
需求描述：【例如：补充具身智能在医疗场景的应用 / 增加一个 MCP 开发者课程】
使用目的：【面试 / 分享 / 工作决策】

请你先调研权威信息源和真实面经/JD，再完成：
1. 判断需要新增哪些知识点，标注层级、优先级（P0-P3）、目标层级（L1-L4）、JD/面经依据和信息源。
2. 设计对应的课程模块（1-3 小时），包含关键问题和实践任务；如已有相关模块则做合并调整。
3. 为每个新知识点生成分层测验题，为高频考点补充面试题和回答框架。
4. 更新对应数据文件的 version 字段，运行语法检查并验证页面正常。
完成后汇报：新增/修改了什么、依据是什么、建议我优先学哪部分。
```

## 收集阶段

```text
我要构建【领域】的知识地图，目标场景是【场景】。
请针对以下节点：【节点列表】
1. 每个节点推荐 2-3 类最可靠的信息源（官方文档、经典教材、权威课程）。
2. 说明每个信息源适合解决什么问题。
3. 提示高质量一手来源的特征和需要避坑的二手来源特征。
不要编造具体链接，优先给可搜索的来源名称和判断标准。
```

## 课程设计

```text
以下是我的知识地图：【粘贴表格】
请帮我设计课程大纲：
1. 把 P0/P1 节点组装成模块，每个模块 1-3 小时。
2. 给出模块依赖关系和建议学习顺序。
3. 每个模块写 3 个关键问题和 1 个实践任务。
4. 说明每个模块的完成标准。
```

## 费曼笔记检查

```text
我正在学习【模块】，以下是我的费曼笔记：【粘贴笔记】
请扮演严格的评审：
1. 指出概念错误和含糊表述。
2. 追问 3 个我可能答不上来的问题。
3. 用一句话判断我是「背下来了」还是「理解了」。
4. 给出需要回到材料重读的具体主题。
```

## 测验生成

```text
基于以下知识点：【列表】
请生成测验题：
1. 每个知识点 L1 识记 1 题、L2 理解 1 题。
2. P0 知识点额外出 L3 应用场景题 1 题。
3. 领域核心主题出 L4 讲授题 1 题。
4. 全部题目附答案要点和常见错误。
```

## 复习迭代

```text
以下是我的测验错题和薄弱点：【粘贴记录】
请帮我：
1. 归纳错误模式（记不住/混淆/不会用）。
2. 为每个薄弱点设计一个 30 秒可回忆的记忆锚点。
3. 生成未来 30 天的间隔复习计划（1/3/7/14/30 天）。
4. 标出需要回到学习阶段重学的知识点。
```

## 分享准备

```text
我要给【受众】做【时长】分钟分享，主题是【主题】。
我的知识笔记如下：【粘贴要点】
请帮我：
1. 设计开场问题和大纲（概念 -> 原理 -> 应用 -> 回顾）。
2. 每部分给出讲解要点和过渡句。
3. 预判 5 个听众提问并给回答要点。
4. 指出哪些内容对这个受众可以删掉。
```

## 面试准备

```text
我要准备【岗位/方向】面试，考察领域是【领域】。
我的知识笔记如下：【粘贴要点】
请生成：
1. 15 道高频面试题，按 L1-L4 分层。
2. 每题给出「结论先行 -> 原理 -> 场景 -> 取舍」的回答框架。
3. 标注加分项和常见误区。
4. 模拟一轮追问，检验我的理解深度。
```
