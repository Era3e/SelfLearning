### 高频能力要求（按出现频率）

1. **LLM 基础原理**：理解大模型能力边界、Token、上下文窗口、多模态。
2. **Prompt Engineering**：提示词设计、结构化输出、Few-shot。
3. **RAG 架构**：知识库、检索、向量库、Rerank、效果调优。
4. **Agent 核心组件**：Tool Calling / Function Calling、Memory、Workflow 编排。
5. **Agent 评估（Eval）**：端到端效果追踪、评测集设计、调优、成本控制。
6. **Multi-Agent 与生态**：MAS、Agent 市场、开发者协议、MCP。
7. **B 端产品能力**：低代码平台、复杂系统抽象、业务场景落地。
8. **产品通用能力**：需求洞察、PRD、跨团队协同、商业化思维。

### 对知识地图的输入

- 基础层必须覆盖 LLM 原理与 Token/上下文等概念。
- 核心层重点投入 Prompt、RAG、Agent 组件、评估。
- 应用层覆盖低代码 Agent 平台、B 端场景、成本与治理。
- 前沿层覆盖 Multi-Agent、MCP、多模态趋势。

### 高频能力要求

1. **机器人产品全周期**：场景调研、需求定义、原型、量产落地、交付路径。
2. **硬件集成与人机交互**：端侧指标、硬件约束、交互逻辑、安全性。
3. **感知-决策-控制链路**：视觉导航、运动控制、规划算法的基本理解。
4. **具身智能模型**：VLA（Vision-Language-Action）、模仿学习、世界模型、强化学习。
5. **机器人形态**：协作机械臂、AGV/AMR、人形机器人、服务机器人。
6. **数据与评估**：多模态数据、仿真到真机、指标证明可迭代性。
7. **商业闭环**：定价、交付、客户采纳率、复购、行业解决方案。
8. **产品通用能力**：竞品分析、用户调研、PRD、跨团队协同。

### 对知识地图的输入

- 基础层覆盖机器人学概念、坐标系/运动学、控制系统、传感器。
- 核心层重点投入感知、SLAM/导航、运动规划、VLA 与机器人学习。
- 应用层覆盖产品形态、量产交付、场景选型、商业闭环。
- 前沿层覆盖世界模型、人形机器人、Sim2Real、数据飞轮。

## 三、两个方向的共同结论

1. 招聘方都要求「技术理解 + 场景抽象 + 落地闭环」，不是纯技术深度。
2. AI 方向核心资产是 LLM/RAG/Agent/Eval；机器人方向核心资产是感知-决策-控制 + VLA。
3. 面试高频问题集中在：能力边界判断、方案选型、指标定义、风险评估。
4. 产品经理需要能讲清「为什么用这个技术、什么时候不用、怎么衡量效果」。
