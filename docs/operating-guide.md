# 操作指南

本文说明如何从零跑通一个新领域。以「AI 技术知识」为例，其他领域同样适用。

## 第 0 步：创建领域目录

1. 复制 `domains/_template/` 为新目录，例如 `domains/ai-tech/`。
2. 按 `_template/README.md` 的文件清单，从 `docs/templates/` 复制模板。
3. 打开 `00-brief.md`，开始定向阶段。

## 第 1 步：定向

用时建议：30-60 分钟。

1. 填写《领域立项简报》（`00-brief.md`）。
2. 重点打磨三处：
   - 目标场景写成具体事件，例如「11 月给团队做一次 30 分钟 AI Agent 分享」。
   - 深度边界写成取舍，例如「重点掌握 Agent 架构与评估，暂不深入模型训练」。
   - 验收标准写成可检查的行为，例如「能回答 20 道场景题且正确率 80%」。

退出条件：简报中的目标、边界、时间、验收标准全部填写且无待定项。

## 第 2 步：收集

用时建议：2-3 小时，分散进行。

1. 按《知识地图》模板（`01-map.md`）搭建领域分层结构。
2. 每个节点标注优先级（P0-P3）和目标层级（L1-L4）。
3. 收集信息源时先记录到模板，不急于深读。
4. 用优先级矩阵裁剪：P3 节点移入「暂缓区」，不进入课程。

退出条件：地图覆盖目标场景所需知识，P0 节点均有信息源。

## 第 3 步：课程设计

用时建议：1-2 小时。

1. 把 P0/P1 节点组装成课程模块，填写《课程大纲》（`02-curriculum.md`）。
2. 每个模块控制在 1-3 小时学习量；超过则拆分。
3. 为每个模块设计一个实践任务，例如画架构图、写对比表、做选型决策。
4. 排序原则：先基础后应用，先 P0 后 P1，先满足近期分享/面试需求。

退出条件：所有 P0 节点都归属某个模块，且模块有完成标准。

## 第 4 步：执行学习

每个模块按固定节奏执行：

1. 预习：读材料前先看模块的关键问题，带着问题读。
2. 学习：阅读或观看材料，随手记录关键概念。
3. 整理：用《费曼笔记》（`03-notes.md`）复述，禁止照抄原文。
4. 自测：合上材料回答关键问题，答不出的部分标记为薄弱点。

模块完成标准：费曼笔记写完 + 关键问题全部答出。

## 第 5 步：检验

每个模块学完后立即小测，整个领域学完做总测。

1. 用《测验记录》（`04-assessment.md`）生成题目：L1/L2/L3/L4 各至少一题。
2. 测验后立即批改，每个知识点标记状态：通过 / 薄弱 / 未掌握。
3. 薄弱和未掌握知识点进入《复习计划》（`05-review.md`）。

领域级检验额外包含：
- 一次 10 分钟费曼讲解（录音或写作均可）。
- 一份《分享大纲》（`06-share.md`）。
- 一份《面试题库》（`07-interview.md`），含标准答案要点。

## 第 6 步：复习迭代

1. 按 1/3/7/14/30 天间隔执行复习，形式以回忆为主、重读为辅。
2. 每次复习后更新知识点状态和下次复习日期。
3. 领域结束时写《领域复盘》（`08-retro.md`），检查目标达成度和模板改进点。
4. 复盘中发现的模板问题，直接修改 `docs/templates/` 下的对应模板。

## 每周节奏参考

假设每周 5 小时：

| 时间 | 动作 |
| --- | --- |
| 周一 1h | 学习新模块 |
| 周三 1h | 学习新模块 + 费曼笔记 |
| 周五 30m | 本周测验 |
| 周末 1.5h | 复习薄弱点 + 下周计划 |
| 碎片 1h | 收集材料、整理面试题 |
