# 新领域目录模板

使用方法：

1. 复制本目录为 `domains/<领域名>/`，例如 `domains/ai-tech/`。
2. 从 `../../docs/templates/` 复制所需模板，按以下命名放入本目录。
3. 按 `../../docs/operating-guide.md` 依次执行。
